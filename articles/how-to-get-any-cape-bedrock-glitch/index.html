How Minecraft Bedrock Players Are Getting Every Cape in the Game

A years-old bug in Minecraft Bedrock Edition's cape API has been rediscovered, and it lets players equip literally any cape in the game. This includes ones from versions that came out long after the bug was introduced. Here's how the glitch works, how it went viral, and another way to get these capes without downgrading your game.

The Glitch That Unlocks Every Cape

Capes in Minecraft are normally tied to specific promotions, events, or gatherings that allow you to unlock them for a limited time. However, a bug in the game's marketplace API has given players a way around that entirely. By downgrading their game to an older version on PC, players are able to open up the full cape library and equip anything in the list, whether or not they were ever meant to have it.

The Downgrade Method - Version 1.16.0

The method centers on Minecraft Bedrock Edition version 1.16.0. On PC, players are rolling their game back to this specific version using third-party launchers. Once running on 1.16.0, the cape selection screen doesn't correctly check which capes a player is actually entitled to - so every cape in the list, including ones added in versions released years after 1.16.0, is visible and able to be selected.

1
Downgrade to 1.16.0: On PC, switch your Minecraft Bedrock installation to the legacy version 1.16.0. This can be done with a variety of tools, like Citrine Launcher. If using another launcher, make sure to ensure that it is safe!
2
Open your cosmetics screen: With the game running on 1.16.0, head into the character character creator menu and open the Capes tab on the left navigation bar.
3
Equip any cape: Select any cape shown in the menu and equip it.
4
Update back: Update to the latest version, or switch to another console entirely. The cape is saved directly to your skin data, so it stays equipped either way.

How the Glitch Gained Attention

The bug started gaining real traction after Minecraft YouTuber ItsMe James posted a video breaking down the exploit and how to reproduce it. Posted on June 29, 2026, the video has since passed 50,000 views, introducing a much wider audience to the method.

A month later, on July 29, 2026, another large Bedrock-focused content creator ibxtoycat covered the same glitch in his own follow-up video, pushing the glitch further into the mainstream Bedrock community. Both videos are worth watching directly if you want the full breakdown of the mechanics behind the bug.

One of the most interesting side effects of the glitch is that it exposes the Mojang Studios Cape - a cape that's normally reserved exclusively for Mojang employees and has never been obtainable by regular players through any legitimate method. Because the 1.16.0 API displays every cape in the game when prompted, it shows up in the list right alongside promotional and limited-time capes.

This Bug Isn't New - It's Been There Since 2020

What most players don't realize is that this isn't a new exploit at all. Version 1.16.0 originally released back in June 2020, and the API behind its cape system has never been patched or updated since. In other words, this bug has technically been sitting there, fully functional, for years - it simply took until mid-2026 for it to be present to a larger audience. If you were on 1.16.0 at any point in the last several years, all of the capes were already available to you!
